# Trabajoleoestacion
The present project consists of the design, construction, and commissioning of a prototype weather station using IoT technologies, capable of monitoring environmental variables and air quality. It operates with two communication protocols (LoRa and WiFi).
The development of the project consists of two stages: the first stage involves the design of the electronic system and the selection of variables to be measured; the second stage consists of a series of tests in which the performance of the system will be analyzed under real conditions, in order to make possible improvements for a future expansion into a network of weather stations throughout the municipality.
The prototype was tested under real conditions on the rooftop of the Tuluá city hall, where it is currently installed. The data obtained was visualized on the Marso Smart Cities platform, allowing access and analysis from any device with an internet connection. Different technological options and communication protocols were explored. Finally, it is highlighted that the project successfully meets the need to transmit the data measured by the sensors. 
This prototype provides a solid foundation for a future network of weather stations, encouraging innovation and driving the municipality toward its transformation into a smart city.
